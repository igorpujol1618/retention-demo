# retention-demo

Measuring retention with SQL and testing it with statistics, using public data from a Brazilian e-commerce marketplace and a real A/B test.

> **Status:** work in progress. Findings will be added as each part is completed.

## Who this is for

Marketing, product and data analysts who want to go beyond "how many customers bought" and answer "how many come back, and why".

## What's inside

| Part | Question | Dataset |
|---|---|---|
| **A. Measure** | How many customers buy again, how soon, and what drives it? Cohorts, activation, LTV and RFM, all in SQL. | Olist |
| **B. Compare** | Does a product analytics tool tell the same story as SQL? | Olist, as events in Mixpanel |
| **C. Test** | Did moving a game's first gate change player retention? SRM check, power analysis, frequentist vs. Bayesian reading. | Cookie Cats |
